# Invertis Campus Connect College Club

A responsive four-page college club website built with HTML and CSS for **Invertis University**. This project was created as part of the Web Development Day 04 assignment.

## Pages

- `index.html` — Club introduction, mission, and calls to action.
- `about.html` — Club story and accessible event schedule table with a caption, `thead`, `tbody`, `tfoot`, and `colspan`.
- `registration.html` — Student registration form and volunteer application demonstrating native HTML5 validation and diverse input types: text, email, password, number, date, URL, telephone, time, radio, checkbox, select, textarea, file, and submit controls.
- `contact.html` — Club contact details, campus address, and a structured feedback/message form.

All four pages share consistent navigation, a responsive stylesheet (`styles.css`), viewport and description metadata, and an SVG favicon.
